# Tribuen Download Admin — Android

Aplikasi WebView untuk halaman admin download bot Tribuen Global.

Alamat: https://tribuenglobal.com/bot-download/admin.php

## Build di GitHub
1. Buat repository **private** baru di GitHub.
2. Upload **isi** folder proyek ini (bukan folder pembungkusnya), termasuk folder `.github`.
3. Buka **Actions** > **Build Tribuen Download Admin APK** > **Run workflow**.
4. Setelah sukses, buka run > **Summary** > **Artifacts** > **Tribuen-Download-Admin-APK**.
5. Ekstrak ZIP dan instal file APK pada HP Android.

Catatan: Ini APK debug untuk penggunaan/pengujian pribadi. Jangan mengunggah password, API key, atau file konfigurasi server ke repository.
